# 自动999 · AutoReviveHelper

一个 FF14 Dalamud 插件，专门解决「死了没人管」这个破事。

## 它到底解决什么问题

在新月岛刷无限塔、在博兹雅蹲 CE，一个人做的时候死了，最烦的不是掉血，是：

1. **没人知道你死了** —— 公屏不喊一句，路过的玩家根本不知道你在哪一滩。
2. **喊一次就沉底** —— 几十秒就被别人的招募刷走了，后面来的人根本没看见。
3. **干等不知道等多久** —— 等到掉线？还是认罚返回入口？返回有死亡惩罚，可不去又卡那儿动不了。
4. **别人来拉了你还得盯着屏幕点确认** —— 你去倒杯水的功夫就错过了。

这四件事，插件全部替你做。

## 它帮你做的四件事

### 1. 死了立刻喊 999 + 坐标

死亡状态一出现，自动在频道里发一句：

```
999 蜃景幻界新月岛 北征之章 (X:22.3 Y:15.1) 救救我
```

地图名和坐标是自动取的，你不用手打字。频道默认队伍 `/p`，可以改成喊话 `/sh`、呼喊 `/y`、同盟 `/a`。

### 2. 没人来就一直喊

默认**每 1 分钟重喊一次**，不会喊一遍就沉底。直到你被救起来或者超时返回。

间隔可以调，设成 0 就是只喊一次。

### 3. 超时自动长按「返回入口」

死了超过 **5 分钟**还没人来救，如果这时候弹出「即将回到『XXX』的开始地点」那个框，插件会自己去长按【确定】。

另一个按钮是【保留】——那等于继续等人救，插件**绝不碰它**。

所以逻辑是：**能等就多等一会儿，实在没人才认罚返回**，不会一死就放弃。

### 4. 别人拉你，秒接

复活确认弹窗一出现就自动点「是」。

这一条是**白名单**的：只有弹窗内容带「复活 / 復活 / 复苏 / 甦 / raise / revive / resurrect」才动手，
组队邀请、买地确认、放弃任务这些一律放过，不会替你做别的决定。

### 5. 被救活，自动道谢

站起来的那一刻自动发「谢谢！！！」，文案可以自己改。

## 什么时候用它

### 强烈推荐

**博兹雅战线 / 扎杜诺尔高原** —— 刷 CE、蹲 FATE、单人做任务。死了旁边没人，全靠公屏喊人。
配合喊话间隔，能被路过的玩家捞起来的概率明显高。

**蜃景幻界新月岛** —— 跑无限塔、挖宝。这里死了会弹返回入口的框，但返回有死亡惩罚，
所以「多等一会儿」特别有价值。插件就是为这个场景设计的。

### 可以用但注意

**挖宝 / 深层迷宫 / 单人副本** —— 一样是单人场景，死了没人管。但返回机制不同，超时返回那条**建议关掉**。

### 不建议

**八人本 / 四人本** —— 有治疗看着你，自动接受复活反而可能打断机制。
真想用就只留喊话，把自动接受和超时返回都关掉。

## 怎么装

进游戏，聊天框输入 `/xlplugins`，点「设置」→「实验性功能」→「第三方插件源」→「+」新增，填：

```
https://raw.githubusercontent.com/arcnapan/AutoReviveHelper/main/pluginmaster.json
```

保存后回插件列表点「刷新」，找到「自动999」，勾上启用。

> 加不上、下载失败，多半是国内直连 `raw.githubusercontent.com` 被掐。挂代理再试，或者用下面的手动方式。

**手动装**：把仓库里的 `latest.zip` 下载下来，解压到：

```
%APPDATA%\XIVLauncherCN\installedPlugins\AutoReviveHelper\1.3.3.0\
```

重启游戏，`/xlplugins` 里启用。

## 怎么用

| 命令 | 作用 |
| --- | --- |
| `/autorevive` | 打开设置窗口 |
| `/autorevive on` | 快速开启 |
| `/autorevive off` | 快速关闭 |
| `/autorevive lang zh` | 切中文界面 |
| `/autorevive lang en` | 切英文界面 |

装完先干三件事：看一眼总开关是不是开的、想排查问题就把「调试」分区打开、确认频道是 `/p`。
然后正常玩就行，不用管它。

## 调试模块（1.3.0.0 起独立成模块）

调试不再是散在主流程里的一句话，单独收进了 `DebugModule`，自己决定要不要开：

- **开关与位置**：设置窗口最下面有个折叠的「调试」分区，不点开根本看不见，平时界面保持清爽。勾「输出调试日志到聊天框」才真正往聊天框打。
- **详细程度**：`普通` 只打关键事件（死亡、复活、超时、区域切换）；`详细` 连每帧轮询的中间状态也打——卡在哪一步判断的时候才用得上。
- **双重输出**：插件日志（`dalamud.log`）永远写，不受开关影响，出问题时翻日志总能拿到线索；聊天框只有开关开着才写。
- **会话计数**：窗口里直接显示本次会话打了多少条调试、喊了几次话、接受了几个复活、超时返回命中几次、区域自动开关几次。不用翻日志就知道它到底动没动。
- **最近几条**：分区里还会把最近 5 条调试事件列出来，瞄一眼就够。

## 中英文切换

设置窗口顶部有语言下拉，选完下一帧就变，不用重启插件，也不用重开游戏。

- 界面文案、提示信息、区域名（博兹雅 / Bozja、新月岛 / Occult Crescent）全部跟着切。
- 命令行也行：`/autorevive lang zh` 或 `/autorevive lang en`。
- 文案表在 `Loc.cs`，一条 key 对应中英两句。单测会把每个 key 都过一遍，少一条直接红——所以切到英文不会出现空着的地方。

| 总开关 | 开 | 关掉后插件完全不动作 |
| 死亡喊话 | 开 | 死了自动喊 |

| **调试日志** | **关** | 独立调试分区，可自选开关与详细程度（普通 / 详细） |

## 进区域自动开关是怎么判的

不写死地图 ID，而是看地图内部代号（`TerritoryType` 表的 `Name` 字段）前缀：

- 博兹雅系列 `n4b*` / `n4e*` —— 南方博兹雅战线 920、扎杜诺尔高原 975、甘戈斯 915、燕鸥崖 919、通信雷波塔 913、女王古殿 936、失落的遗迹 964
- 新月岛系列 `o6*` —— 新月岛南部 1252、幻境村 1269、航船甲板 1277

前缀比 ID 稳，以后加子场景大概率自动覆盖。代号取不到时退回已知 ID 白名单兜底。

三个细节：

1. **只关自己开的**。进去前本来就开着，离开时不动它。
2. **手动 `/autorevive off` 之后本次登录不再自动开**，免得你刚关掉它又给你打开。
3. 优雷卡四张（`z3f*`）**不算**这两类，不会触发自动开启。

## 长按返回是怎么做的

`AddonSelectYesno` 里那个「确定」按钮是个长按组件 `AtkComponentHoldButton`（槽位 `AtkComponentHoldButton278`）。

插件的做法是：往它注入 `AtkEventType.MouseDown`，每帧推进 `Progress.CurrentValue`，
到 `TargetValue` 就注入 `MouseUp` + `FireCallbackInt(1)`。
如果 `HoldPressSeconds` 秒过去官方进度条还没走完，就把 `CurrentValue` 直接顶到 `TargetValue` 兜底。

> 为什么不直接执行 `/return`？因为 `/return` 是回主城，而这里要回的是副本/战线的入口，
> 两者死亡惩罚完全不同。游戏里也没有可直接调用的「返回入口」指令，只能点这个弹窗。

## 已知限制

1. 长按这条没法在所有机器上预先验证。第一次用建议开调试日志，看聊天框有没有打出「死亡已超过 X 分钟无人救助，准备返回入口」。
2. 某些版本的长按组件可能不是 `AtkComponentHoldButton278`（还有 `280` / `288`），真遇到没反应就把 `dalamud.log` 发出来。
3. 坐标换算依赖当前地图行数据（`Map` 表的 `SizeFactor` / `OffsetX` / `OffsetY`）。取不到时退回粗略换算，日志里会写明。取到的时候和地图读数一致。

## 坐标是怎么算出来的

用的是 Dalamud 自带的 `Dalamud.Utility.MapUtil.WorldToMap`，按当前地图的 `SizeFactor` 和 `OffsetX/Y` 换算，
不是自己推的公式。

> 1.3.2.0 之前这里有个真 bug：自己写的公式把 `sizeFactor/100` 当成 `mapScale`，
> 算出负数缩放，精确坐标永远停在 1.0。现在整段换成了内置实现。

游戏里的世界坐标是（东西、高度、南北），地图读数是（东西、南北），换算时 Y/Z 会换位，这是 `MapUtil` 自己处理的。

## 文件说明

- `pluginmaster.json` —— 插件源清单，Dalamud 读这个
- `repo.json` —— 同一份内容的备用文件名（部分老版本认这个）
- `latest.zip` —— 插件本体包

## 发版流程

```powershell
cd D:\DEV\AutoReviveHelper\AutoReviveHelper
dotnet build -c Release -p:DalamudLibPath="$env:APPDATA\XIVLauncherCN\addon\Hooks\dev\"
```

产物在 `bin\Release\AutoReviveHelper\latest.zip`，复制到本目录，然后：
- 改 `pluginmaster.json` 和 `repo.json` 里的 `AssemblyVersion`
- `git add -A` + `git add -f latest.zip`（`.gitignore` 会挡 zip，必须 `-f`）
- `git commit` + `git push`

**1.3.3.0** —— 移除对 `Dalamud.Excel.Sheets` 的运行时依赖。国服 Dalamud 安装包不带这个 dll，之前一查地图表就抛 `FileNotFoundException`，聊天框会被刷屏；现在改用不碰 Excel 表的方式取参数，坐标走与地图尺寸无关的兜底换算

上一版 **1.3.2.0** —— 插件改名「自动999」；坐标换算整段换成 Dalamud 内置 `MapUtil.WorldToMap`，修掉精确坐标恒为 1.0 的老 bug；补坐标回归测试

再上一版 **1.3.0.0** —— 调试独立成模块（可自选开关与详细程度、会话计数）；界面中英文切换（窗口下拉 + `/autorevive lang zh|en`）
